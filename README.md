# homebrew-tap

Homebrew tap for [cavoco](https://github.com/cavoco)'s apps.

## Usage

```sh
brew install --cask cavoco/tap/preview3mf
```

Or tap first, then install:

```sh
brew tap cavoco/tap
brew install --cask preview3mf
```

## Casks

- **[preview3mf](https://github.com/cavoco/Preview3MF)** — macOS Quick Look extension for `.3mf` files. Press Space in Finder for a 3D preview and rendered thumbnails, no slicer needed.
